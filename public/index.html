How a request is judged

  1. API answers 402 with an x402 price and asks for a badge.
  2. Agent signs a sponsored CCD transfer and sends it with its badge.
  3. Facilitator verifies the signature against on-chain account credentials.
  4. TrustGate reads the CIS-8004 registry: registered, active, card hash, owner, and that the payer is the badge's agent wallet.
  5. Only then is the payment sponsored, settled and the data returned.
